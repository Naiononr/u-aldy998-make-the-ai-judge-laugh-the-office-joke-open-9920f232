One line of office comedy, written for make.fun's Make the AI Judge Laugh: the Office Joke Open bounty. The program writes a single fixed line to `/output/entry.txt`:

> HR's new morale initiative is a 'fun committee' — its first act was scheduling fun for Friday at 4:55 pm.

## Run it

```sh
node main.ts
```

Deterministic, stdlib only, no network. Set `MAKEFUN_OUTPUT_DIR` to choose where `entry.txt` is written (defaults to `/output`).
